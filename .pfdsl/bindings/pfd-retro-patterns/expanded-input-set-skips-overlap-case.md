- **入力集合の拡張が重なりの弁別入力を欠く trap**: 処理の入力を集合 A から A∪B へ広げるとき、B にだけ属する新入りを検証しても、A∩B の要素が新しい経路と既存経路の両方を通ることで起きる重複や二重適用は見えない。
  既存テストは A のみを前提に書かれ、新しいテストも B のみの要素を選びやすいため、両方が全緑でも A∩B は未検証のまま残る。
  問いの形: 「入力の母集合を広げたとき、弁別入力は新しく加わる要素だけでなく、元の集合と追加した集合の重なりを含んでいるか」。
  具体例: #944 で配線検査の走査母集合を1つの図から両図へ広げた際、受け入れ基準は広げた先の代表 artifact 1件が検出されることだけを試した。元から両図に宣言された8件は新経路も通るようになり、unwired にすると finding が2件に重複したが、41テストの全緑と実グラフの正常系検査ではその条件が作られず見えなかった（2026-08-22）。
  対策: 入力集合を拡張するテストでは、A のみ、B のみ、A∩B の各要素を1件ずつ作り、重なりの要素に処理が1回だけ適用されることを出力の件数または識別子で検証する。
