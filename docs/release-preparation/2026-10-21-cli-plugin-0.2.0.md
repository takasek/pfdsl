# CLI/plugin v0.2.0 公開準備

## 対象と境界

2026-10-21。対象区間は公開 tag `v0.1.0` から `b008ba8b43e5dc35f0c5d2b9d41f8ade2187a3c4` まで。
CLI/plugin の準備版は v0.2.0 とする。`status ready --best` と `best` JSON field の撤去、および N004・V036 の追加を含むため、0.1.x の patch としては扱わない。仕様版は v0.0.28 のままで、ライブラリ・VS Code 拡張・standalone の公開は含めない。
#1319 は公開後の採用先3件による適用・検証・記録・同一 plugin での再照合まで OPEN を維持する。準備 PR は `Refs #1319` と閉じない理由、行頭 `no-issue:` を使い、`Closes` を付けない。
公開・tag push・marketplace pin 変更・#1319 への公開結果コメントは未実施。公開実体確認後に同 issue の公開担当プロンプトに従って報告する。
