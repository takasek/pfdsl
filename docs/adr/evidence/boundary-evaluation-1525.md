# #1525 境界判定の受入評価

## 固定した対象と方法

[独立参照集合](boundary-reference-1525.md)の11件への差替えは、文案の評価前に所有者が承認した。
評価者は実装時の対話を引き継がない別 agent であり、[0段目](boundary-evaluation-1525-rule.md)と[原文・条件](boundary-evaluation-1525-inputs.md)だけを読んだ。
期待配置を含む参照集合、ADR、他の設計資料は渡していない。
初回と再評価は同じ評価者が担当したため、再評価は新規の盲検ではない。

## 初回からの修正

[初回の規則](boundary-evaluation-1525-rule-v1.md)と[初回結果](boundary-evaluation-1525-reader-v1.md)を残す。
初回はR5のdone遷移に基づくモデル監査と実行時点の境界、および「主語」が文法上の主語なのか判定対象なのかが曖昧だった。
0段目へdone eventの監査対象・非適用条件と実時間の区別、主語が判定対象を意味することを追記した。
C1について、ADR-0048 D2が持つ第三者部品の固定説明本文の限定例外も0段目から取得できるようにした。
例外の範囲は広げていない。

## 最終照合

[最終回答](boundary-evaluation-1525-reader.md)と、先に固定した参照集合を実装担当が照合した。
全11件について、要求した配置・分離・保持条件を再現できた。
単一のラベル11個の一致としては数えない。

| 件 | 確認した内容 |
| --- | --- |
| R1 | 完了根拠とcommit時点を分離し、基準差替えの許可条件を削除しない |
| R2 | hook/agentの語があってもモデルへの参加者性を中核に残す |
| R3 | 変換とモデルの整合を残し、同一PRの時点規則を分離する。採用状態・location未取得を非該当としない |
| R4 | 構造的事実と一般的な手続き散文を分離する |
| R5 | done契機のモデル監査と会話ターン・実時間の規律を分離する |
| R6 | 強制の1プロセス規則を中核に入れず、変更可能な既定値への変更が意味変更であることとprocess/run対応を保持する |
| R7 | bindingへの追従スロットと未提示の追加手順の分類を分ける |
| R8 | L3契約未取得を契約なしや区分iiと断定しない |
| C1 | 配布アダプタと実行者の外部書込みを分け、固定本文の限定例外を一律免除に広げない |
| C2 | 付属機能を中核とせず、新しい汎用チェックの受入口にしない |
| C3 | 配布機構とモデルが表す変換の整合を区別する |

R3の「同じ変更束」がPRと独立した意味を持つか、R6の「大きすぎる」の具体的基準、R7の参照先、R8の契約実体は入力不足として残る。
これらを正解確定や検査済みにしていない。
R4の原文の広すぎるcompanionへの配置は、分類基準が検出した原文側の問題として残る。

## 限界

起票時の6規則との同一性・網羅性、一般的な誤分類率、偽陽性と偽陰性の同時改善は検証していない。
目的抽出した11件に対する文章の受入評価であり、未知の規則に対する一意性を保証しない。
E0の成否はこの受入に使っていない。
初回評価と修正内容を開示したうえで、この集合に対する受入を満たしたと判断する。

## PRレビュー後のファイル識別の補足評価

2026-10-24のPRレビューで、process IDがファイルローカルである点を証拠の対応へ明記する不足を指摘された。
ADR-0051と0段目に、対象モデル版の文脈でPFDファイルを一意に識別する情報と、そのファイル内process IDの組を明記した。
上記11件の保存済み入力・回答は当時の評価版として保持し、今回の追記を当時評価済みだったことにはしない。

実装対話を引き継がない別agentが、変更後の0段目だけを先に読み、次の3ケースを判定した。
前提は同一リポジトリの同一revisionに `a.pfdsl` と `b.pfdsl` があり、双方が `review` というprocessを持つ場合である。

| 証拠 | 独立評価者の判定 |
| --- | --- |
| revisionとprocess IDだけ | 対象ファイルを確定できず、パス等の識別情報が必要 |
| revisionと `a.pfdsl` のパス、process ID | aのreviewへ確定可能 |
| 単一のbを一意に指すモデル識別子とprocess ID | 提示されたrevisionの文脈ではbへ確定可能。識別子が版を区別しない場合は版の文脈も必要 |

その後の最終差分レビューでは仕様 §2.9.1、ADR-0048/0051、ADR一覧、正本と4ミラーの整合が確認された。
グローバルID、新しいPFDフィールド、保存方式の追加要求はしていない。
