# Standalone の独立レビュー記録と課題分析

2026年10月27日の Astra・Sol と、28日の Claude による pfdsl standalone app の独立評価を保存する。
観察の一致、評価の違い、確認条件の差を残し、課題と解決案を分けて検討するための記録である。
改善の採用、実装順、issue 化は決定していない。

## 対象版と評価条件

| 対象 | 固定 commit |
| --- | --- |
| pfdsl | `d1b5db85ecdb9344a5ed6fff2f1b17632a8ec6e6` |

Astra は GPT-6 Astra、Sol は GPT-6.1 Sol を指定して別チャットで起動した。
依頼文と参照資料パックは共通で、他方の成果物や過去評価の結論を読まずに評価するよう依頼した。
Astra・Sol は macOS ネイティブ版と共有フロントエンドのブラウザ表示を操作し、実装を照合している。
Astra のネイティブ環境は評価専用の識別子等を指定した dev／debug 構成、Sol は識別子を変更した release build である。
同じ commit でも配布アプリと同一の実行条件ではない。
ブラウザの幅変更はネイティブウィンドウの狭幅受入を代替しない。

記録用 worktree の起点は `8d4962064d694d1b23c9928287fa0c83eb0d871a` で、評価対象より後の版である。
保存時に製品の再評価は行っておらず、以下の所見は固定した評価対象版に限る。

環境の詳細は [Astra の環境記録](astra/README.md)と[Sol の環境記録](sol/README.md)を参照する。
両者とも macOS 27.0.1（26A434）、Node v26.12.1、pnpm 10.33.2 を記録している。
ブラウザ版・WebKit 版は未取得で、Sol は推奨 Node 24 との差も記録している。

Claude の[追加評価と環境](claude/README.md)も同じ製品版を対象とする。
OS は macOS 27.2（26B123）と自己記録しており、他二者と条件が異なる。
ネイティブの縮小ウィンドウ・保存衝突などを追加観察したが、Open は事前に作った Recent を使い、Save As 等は未確認である。

## 保存範囲

pfdsl のレビュー・操作記録・環境条件と主要な証拠15ファイルを収録した。
他製品の利用記録は収録対象から除き、pfdsl の課題分析を残した。
全原本はローカルのセッション成果物領域に保持している。

保存報告は pfdsl に関する部分の抜粋で、原本と保存版の SHA256 を provenance.json に記録した。
私的パスを除き、収録資料へのリンクを付け替え、未収録の根拠は「原本限定資料」と表記している。
画像2点は公開保存には含めず、ローカル原本に保持した。
参照画像パック、HIG 本文、実行ファイルは収録していない。

## この記録の適用範囲

三つの評価は共通の依頼・参照資料・製品版に依存しているが、OS・操作ツール・入力文書・操作範囲には差がある。
所見の一致は異なるモデルで同じ現象を観察した根拠にはなるが、初見の人間一般の困難や頻度を統計的に示さない。
三者とも起動 README を先に読んでおり、完全な無予備知識での試験ではない。
VoiceOver、IME、コントラスト、ダークモード、大規模文書、長時間利用、他OSの受入には広げない。
以前の2026年10月13日のレビューとの改善量は、条件を揃えて再測定していないため算出しない。
