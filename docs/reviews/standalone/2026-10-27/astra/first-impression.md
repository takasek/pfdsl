# 初見メモ（実装読取前）

保存版注記：pfdsl に関する部分を抜粋し、その結論・優先度を保持した。絶対パスと資料リンクを保存先に合わせて加工した。収録していない根拠へのリンクは「原本限定資料」と表記する。原文のフォルダ・同梱への言及は全原本フォルダを指す。非リンクの相対ファイル名も、provenance.json の収録一覧にない場合は原本限定資料を指す。

2026-10-27。起動方法を調べる際 README の Editing 節まで読んだため、完全な無予備知識ではない。既知不具合・過去評価は未読。UI実装 main.ts/style.css は未読。

ブラウザ localhost:17429、1280×720 の初見。開始画面は New/Open/Try a sample に絞られ迷いが少ない。サンプルを開くと左右でソースと図が同居し、対応が理解しやすい。主作業面は広い。一方、上辺の Not saved と右端 Not saved to a file の情報重複、上部の細かく連続する枠付きボタン、下の常設診断文が、プロトタイプ的な密度に見える。サンプル3ノードでも小さな minimap があり、少量の内容では重複に見える。図のセリフ書体はソースとUIの書体から離れ、完成図と操作UIの境界とも解釈できるが、統一感は弱い（好みと区別すべき）。

サンプルの design ノードを AX 経由でクリックした直後には変化がない。後続の実画面確認で遅延・ハーネス差を切り分ける。ブラウザでは保存不可の注意が明示されている。ネイティブの保存能力の評価には用いない。
