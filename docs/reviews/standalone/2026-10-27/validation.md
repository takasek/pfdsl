# レビュー記録の保存検査

## 原本と保存版

全原本のローカル複製は Astra 67ファイル、Sol 61ファイルの計128ファイルで、初回保存時に元と複製の SHA256 一致を確認した。
実装の会話・推論を引き継がない別 agent も、その時点の manifest と128ファイルの一致を確認した。

現在の公開保存は、pfdsl に関する報告・環境・テキスト根拠10ファイルに限定している。
原本と保存版の対応・ハッシュは provenance.json に記録した。
pfdsl に関する結論・優先度を保持し、他製品の利用記録を除いた抜粋であることを各報告へ注記した。
画像2点はローカル原本に保持し、公開保存には含めていない。

## 初回保存時の検査

相対リンク、JSON、Markdown の改行、setup-completion、スキル配置・scaffold 同期を検査した。
独立 reviewer は報告・画像と固定版の主要実装を照合した。
環境記録への参照欠落と、原本限定ファイル名の区別に関する2指摘は、環境 README の保存と注記追加で解消した。
この結果は初回保存の検査であり、現在の抜粋版は下記の分離後確認で扱う。

## 分離後の確認

- 相対 Markdown リンク23件は全て参照先が実在した。
- 選択保存12ファイルの SHA256 は provenance.json と一致した。
- 保存した JSON を構文として読戻した。
- 現在の記録に削除資料へのリンクは残っていない。
- 文書の改行と差分の空白検査は成功した。

別 agent が原本・差分・前例を照合し、抜粋が pfdsl の判断根拠と重要な条件を保持しているか確認した。
Sol の参照資料・評価基準まで削っていたという指摘を受け、OmniGraffle／VS Code を参照した段落を復元した。
再確認で指摘は解消し、更新後の provenance 保存版ハッシュも一致した。
この分離レビューに未解決の指摘はない。

## 原報告からの取り落としの照合

Astra の R1〜R4／V1 と Sol の D1〜D5 を、原報告・操作記録・設計検討記録から課題分析へ照合した。
別 agent の照合でも主要課題の脱落はなかったが、表示切替時の状態保持とソース復帰、保存・通知から独立したエラーと鮮度表示、幅変更時の視点保持、Help 展開による図の高さの減少という4点の条件・観察が不足していた。
これらは pfdsl の検討に必要な情報として課題分析へ補った。
他製品の記法・処理系・機能候補は再収録していない。
この照合は原報告の論点を対象とし、製品に未知の課題がないことを示すものではない。
補完後の別 agent による再照合では4点とも解消し、提案条件を製品の受入済み事実へ変えた記述もなかった。
補完した文書の改行検査、差分の空白検査、相対リンク27件の実在確認は成功した。

## 公開用の保存範囲

画像2点の JPEG bytes は公開前チェックの対応形式ではないため、公開版にはテキスト資料と画像の元ハッシュを保存した。
元のローカル記録ブランチは保持し、公開版は同じ base から別ブランチで作成した。
画像参照は原報告・操作記録・AX 記録への参照に付け替えた。
これは新しい実画面評価ではなく、画像からの直接検証はローカル原本に限られる。
公開版の出典対応10件と画像の元ハッシュ2件を別 agent が照合し、原本と一致した。
欠落画像への参照を修正した後の相対リンク25件は全て実在し、文書検査も成功した。

## 検査の限界

保存時・分離時に製品の実操作や HIG 本文の再取得は行っていない。
保存検査は、評価版以後の製品の受入や、原評価の未確認範囲の解消を意味しない。
製品の実装・設定・運用モデルは変更していないため、製品全件テストは今回実行していない。
