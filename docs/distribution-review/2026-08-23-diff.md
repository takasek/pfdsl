## 課題と valid probe

fresh sandbox の採用リポへ Claude plugin bundle だけをコピーし、package・tag push・ローカル検証・upload を別スクリプトとして置いた。
package script は bundle 生成後に tag push 相当の receipt を書き、後段に失敗すると bundle だけが物理的に残る。
利用側メンテナ役には、実在するスクリプトから runtime-pipeline を作り、正常完了時の出力と実データ依存を検証する課題を渡した。

probe は package の正常完了出力を bundle と remote tag receipt の複数出力にし、失敗時の残存 bundle を別の正常出力へ昇格しなかった。
validation は bundle だけを入力にし、upload は bundle と validation receipt を入力にした。
remote tag receipt を validation や upload の入力にする時間順の偽依存は作らなかった。
公開版 CLI の `fmt`・strict `check`・`graph io`・`graph orphans` はすべて成功した。
