## PR #1158 の追加レビューへの対応

上記は初回の記録であり、その後の Claude による敵対的レビューで F1〜F5 の指摘を受けた。

| 指摘 | 対応と確認 |
|---|---|

| F2: phase と案内経路が曖昧 | phase と検索語による候補除外を分け、対象外や未選択を到達確認済みと数えない規定を追加した。実測時の85件中、phaseあり40件・なし45件。PostToolUse の案内は対策本文を元から表示しないため、検証先に使わないと明記した。 |
| F3: 取りまとめ担当の照合結果が残らない | 照合と追加確認の結果・不要と判断した根拠・未確認範囲を、既存の「記録先: PR 本文」項目へ移した。 |
| F4: 主体と文書のみの入口が曖昧 | 「レビューを取りまとめる実行主体（委譲した場合は呼び出し元）」と定義した。レビュー入力を変更対象の成果物とし、実装の入口は実装が存在する場合だけ要求する。 |
| F5: correctness の適用根拠がない | 読み込み処理の入力値が抽出・選択・生成・判定に使われることを正の基準とし、既知カタログの実装と出力経路を示した。既知パス外でも読取経路を探索し、対象外の判断根拠を PR 本文へ残す。固定パス一覧との交差だけで決める新たな機械ゲートは追加していない。 |
